# KeySmash for Mac

Fullscreen fun for little fingers, with a keyboard lock made for Mac.
[Play KeySmash in your browser](https://key-smash-site.vercel.app).

Approved Mac installers and their SHA-256 checksums appear on the
[Releases page](https://github.com/maddox-southard/keysmash-downloads/releases).
One installer supports Apple Silicon and Intel Macs on macOS Monterey 12 or later.

Open the DMG and drag KeySmash into Applications. The early releases are ad-hoc
signed and are not notarized by Apple. If macOS blocks KeySmash, use System
Settings → Privacy & Security → Open Anyway. Follow the app's Accessibility
permission instructions; replacing an older copy may require granting permission again.

To exit play, hold Command + Shift + Escape for 2.5 seconds, then release.
You can also hold the top-left corner for 2 seconds to open parent controls.
An internet connection is required. Game/theme changes arrive when the app opens;
Mac app updates require replacing KeySmash in Applications with a newer download.

This repository contains installers and release notes. Application source is
maintained separately.
